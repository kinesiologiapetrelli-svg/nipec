# I primi trenta giorni · chi fa cosa

Scritto il **13 settembre 2026**, dopo che è venuto fuori che in Albania abbiamo già
**un socio, un avvocato o commercialista, e un medico.**

Questo cambia i tempi: il «Tempo 1 — le carte» non è più due-tre mesi di ricerca di
persone. **Le persone ci sono. I tre filoni partono insieme, lunedì.**

> **Regola:** ogni risposta che torna si scrive qui sotto, con la data e il nome di chi
> l'ha data. Se non è scritto, non è successo.

---

## Filone A — l'avvocato albanese · *la terra e i permessi*

**È il filone che blocca tutti gli altri. Parte per primo.**

| | Cosa chiedere | Risposta | Data |
|---|---|---|---|
| A1 | **Il titolo del terreno è pulito?** Estratto catastale e *titull pronësie* verificati da lui, non dal venditore. Storia dei passaggi degli ultimi trent'anni, eredi, restituzioni post-1991 mai chiuse. | | |
| A2 | **Destinazione d'uso:** sul quel terreno ci si può fare una struttura socio-sanitaria? Se no, che cambio serve e quanto ci vuole? | | |
| A3 | **Vincoli:** idrogeologico, agricolo, archeologico, altezze, distanze. | | |
| A4 | **Che autorizzazione serve** per una struttura residenziale per anziani, chi la rilascia, in quanto tempo, e quanto costa. | | |
| A5 | **Una struttura che ospita solo stranieri paganti** ricade nelle stesse regole di una casa di riposo per albanesi, o in una categoria diversa? | | |
| A6 | **Requisiti di personale e direttore sanitario** imposti dalla legge albanese: chi deve esserci, con che titoli, in che numero per posto letto. | | |
| A7 | **Chi ispeziona**, con che frequenza, e cosa fa chiudere una struttura. | | |
| A8 | **Provvigioni agli intermediari** (i *care broker* inglesi, la *Pflegeberatung* tedesca): cosa si può riconoscere legalmente, e cosa no. | | |

## Quando questi trenta giorni sono finiti, sappiamo

1. Se il terreno **è davvero nostro** e se ci si può costruire.
2. Se l'autorizzazione **si ottiene**, come e in quanto tempo.
3. Quanto costa **davvero** un posto letto, con il costo del lavoro vero.
4. Se i fondi albanesi **ci sono** e **cosa chiedono in cambio**.
5. Se una famiglia europea **dice di sì** — e soprattutto, quando dice di no, **perché**.
6. Come si dividono le cose **fra noi**.

**Con queste sei risposte si va in banca. Senza, no.**
