QUELLO CHE NELLA CARTELLA REMOTA NON SI TOCCA

Nel docroot ci sono gia' dei file che NON vanno cancellati:

  .htaccess     forza l'https. Se sparisce, il sito torna in http
  .well-known   serve al rinnovo del certificato. Se sparisce, fra tre
                mesi il sito mostra "connessione non sicura"
  cgi-bin       si lascia dov'e'

  index.html    QUESTO SI' — e' la pagina "sito in costruzione".
                Il nostro index.html lo sostituisce.

Quindi: NIENTE "svuota la cartella", niente mirror con --delete.
Si copiano i file nuovi sopra, e si cancella solo il vecchio index.html
(che comunque viene sovrascritto).
I file che iniziano con il punto spesso sono nascosti: nel File Manager
va attivata la voce "mostra file nascosti" prima di cancellare qualcosa,
altrimenti si cancella senza vederli.
